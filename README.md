# AI ROBO DINO RUN

AIロボティラノを操作して障害物・レーザー・ボスドローンを突破する、PC/スマホ対応のブラウザランゲームです。

A browser-based endless runner game featuring an AI Robo T-Rex. Avoid obstacles, lasers, and boss drones on both PC and mobile devices.
