# AI ROBO DINO RUN

AIロボティラノを操作して障害物・レーザー・ボスドローンを突破する、PC/スマホ対応のブラウザランゲームです。

## Play

GitHub Pagesで `index.html` を公開するだけで遊べます。

## Controls

- PC: Space / ↑ / W = Jump, Shift / ↓ / S = Dash, P = Pause
- Mobile: JUMP / DASH buttons, tap game screen = Jump

## Features

- PC / Mobile unified layout
- Touchstart optimized controls
- Local high score save
- PWA ready
- GitHub Pages ready
